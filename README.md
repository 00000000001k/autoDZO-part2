# DZO.com.ua — Автозаповнення тендера (Етап 2 + Переможець)

**UserScript** (користувацький скрипт для Tampermonkey / Violentmonkey), який автоматизує рутинне заповнення специфікацій закупівлі та даних переможця на майданчику «Держзакупівлі онлайн» (**dzo.com.ua**) шляхом «розумного» зчитування та аналізу тексту з файлів договорів (PDF, DOCX, DOCM).

---

## ✨ Основні можливості

### 📦 Етап 2: Сторінка редагування тендера (Предмети закупівлі)
* **Зчитування файлів договорів:** Автоматично парсить файли `.pdf`, `.docx`, `.docm`. Вміє розпізнавати скановані сторінки без текстового шару та попереджає про них.
* **Пошук суми та ПДВ:** За допомогою алгоритмів контекстного аналізу знаходить у тексті суму договору та статус ПДВ (*з ПДВ / без ПДВ*).
* **Автоматична перевірка:** Звіряє знайдену в договорі суму з очікуваною вартістю, що вже вказана на сторінці, та за необхідності автоматично виправляє перемикач ПДВ.
* **Розбір специфікації (таблиці):** Розпізнає табличну частину договору, витягує коди **ДК 021:2015**, назви позицій, кількість, ціну та суми.
* **Розумне автозаповнення:**
  * Самостійно відкриває блок «Специфікація закупівлі».
  * Кліками додає потрібну кількість блоків предметів на сторінку.
  * Заповнює назви, кількість, одиниці виміру, місце поставки.
  * **Шукає коди ДК 021:2015 через вбудований довідник сайту** (відкриває iframe, вводить код, обирає та підтверджує).
  * Проставляє кінцевий строк поставки за допомогою jQuery UI календаря сторінки.

### 🏆 Етап 3: Вікно кваліфікації переможця (Власна база ФОПів)
* **Автоматична поява:** Панель з'являється на екрані сама, як тільки на сторінці стає видимим модальне вікно або поля введення даних переможця (`data[suppliers][0][name]`).
* **Контекстна пам'ять:** Автоматично підхоплює розібраний договір з Етапу 2 через `localStorage`. Вам не потрібно завантажувати файл повторно.
* **Розумний пошук ФОП:** Шукає контрагента у вашій локальній базі за кодом ІПН/ЄДРПОУ, або за збігом ключових слів (стемів) ПІБ у тексті договору.
* **Локальна база ФОПів:** 
  * Вбудований менеджер бази (вкладка **«ФОПи»** на будь-якій сторінці сайту).
  * Додавання нових ФОПів в один клік (скрипт сам намагається витягнути ПІБ та ІПН з тексту договору для швидкого створення картки).
  * Можливість редагування, видалення та збереження даних контрагентів.
  * **Експорт/Імпорт бази в форматі JSON** для створення резервних копій або перенесення на інше робоче місце.
* **Автозаповнення картки переможця:** Заповнює назву, код, адресу, індекс, ПІБ контактної особи, телефон, фіксує мікропідприємництво, проставляє суму пропозиції та ПДВ.

## 🚀 Встановлення

1. Встановіть розширення **Tampermonkey** або **Violentmonkey** для вашого браузера.
2. Створіть новий скрипт у розширенні.
3. Скопіюйте весь код файлу `dzo_autofill.user.js` та вставте його в редактор розширення.
4. Збережіть скрипт (`Ctrl + S`).
